# Python Handbook

One place to learn Python from your first program to confident intermediate code, and to prepare for Python coding interviews, without switching between platforms. Each topic combines, in one explanation:
- **the DesignGurus course** you own, *Grokking Python Fundamentals*,
- **classic books**: *Fluent Python* (Ramalho), *Effective Python* (Slatkin), *Robust Python* (Viafore), plus standard algorithms and data-structures material for the interview chapters,
- **official documentation** (docs.python.org, the PEPs, and the numpy, pandas, matplotlib, pytest and mypy docs) and the web, to fill gaps and check facts,
- **real-world examples** from the standard library, popular packages and the products you use.

Every chapter is written for a first-time learner and defines each term the first time it appears. Every code example is a runnable script (Python 3.14, compatible with 3.12+) whose **real output** appears under it. Every chapter was independently reviewed for accuracy.

## How to use it
Every topic follows the same rhythm: *what it is → why it matters → how it works → code with real output → trade-offs → common mistakes → real-world use → in the interview → self-check → TL;DR*. To review, skim the TL;DRs. To check you really learned a topic, answer the self-check questions without looking back.

**Beginner path (read in order):** 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 9, then 10 → 11 → 12 → 13, then 14 → 15 → 16 → 17 → 18. Type the examples yourself and run them. Keep Chapter 21 open as a quick reference.

**Interview-prep path (you already write some Python):**
1. Skim the TL;DRs of Ch 2, 5, 6, 7 and 10 to fill gaps (mutability, list/dict internals, arguments, closures, the MRO).
2. Work through **Ch 19** pattern by pattern, re-typing each solution from memory and running its asserts.
3. Read **Ch 20** (idioms, 13 gotchas, the Q&A) and practise saying the 30-second answers out loud.
4. Go deeper where Ch 20 points you: Ch 11 (generators), Ch 12 (decorators), Ch 16 (GIL, asyncio), Ch 17 (memory, CPython internals).
5. Drill **Ch 22**, the question bank: the ★ questions first, then the output puzzles and coding tasks.
6. The night before, review with **Ch 21** (21.20 maps problem signals to patterns).

## Running the code
All scripts use the shared virtual environment `../.venv-books` (Python 3.14 with numpy, pandas, scikit-learn, matplotlib, scipy, torch, mypy and pytest). Scripts need no network access and no API keys.

```bash
# from python/ — run every example in the book (prints OK / FAIL / SKIP per script)
bash ../tools_run_python.sh python

# run one chapter's script (run it from its code/ folder, because some scripts write to ../img/)
cd chapters/19-python-for-coding-interviews/code
"../../../../.venv-books/bin/python" 08_graphs.py
```
Timings in the outputs (benchmarks, GIL and asyncio demos) depend on the machine; your numbers will differ, but the pattern should not. `chapters/13-type-hints/code/bad_types.py` contains deliberate type errors: the runner skips it, and `04_run_mypy.py` type-checks it instead.

## Rebuilding the PDFs
Requires Node 18+ and Google Chrome (the path is set in `tools/md2pdf.mjs`).

```bash
bash tools/regen_pdfs.sh      # every ChapterNN-Notes.pdf + Python-Handbook.pdf (cover title "Python Handbook")

# one chapter only
node tools/md2pdf.mjs chapters/19-python-for-coding-interviews/Chapter19-Notes.pdf chapters/19-python-for-coding-interviews/README.md
```
`md2pdf.mjs` reports any Mermaid errors or broken images.
