display: block — own line; width/height apply (with width: auto it would fill the line)

Text before block span text after.

display: inline — flows inside the line; width/height ignored; vertical padding overlaps neighbours

Text before the inline span inline span with padding and the text keeps going on the same line, wrapping naturally at the edge of the paragraph like ordinary words, while its vertical padding spills over the lines around it.

display: inline-block — sits in the line like a word, but width/height/padding all push things away

Text before inline-block span text after, on the same line.

display: none — no box at all (the space closes up)

Text before you can't see metext after.
