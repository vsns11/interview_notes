Floats were designed for exactly this: an image or pull quote pushed to one side while the surrounding lines of text flow around it like water around a rock. The line boxes shorten to make room, but the paragraph's own box still starts at the left edge underneath the float. Once the text passes the bottom of the float, lines return to full width, as this sentence shows when it wraps below the blue box on a narrow enough page. Here it does: this last line runs under the float, all the way from the left edge to the right edge of the dashed parent box.
